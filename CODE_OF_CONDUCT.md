# Code of conduct

## The short version

Be decent. Argue about code, not about people.

## What is expected

- Assume good faith. Most disagreements are misunderstandings about context.
- Critique the work, not the person. "This bypasses the WAF when the body is
  chunked" is useful; "this is amateur" is not.
- Accept that maintainer time is finite. An unanswered issue is a queue, not an
  insult.
- Respect that contributors write in a second language. Correct the technical
  content; do not mock the English, Russian or Chinese.
- Report security issues privately. See [SECURITY.md](SECURITY.md).

## What is not acceptable

- Personal attacks, harassment, or discriminatory language of any kind.
- Publishing someone's private information.
- Deliberately derailing discussions, or repeatedly reopening settled decisions
  without new arguments.
- Using this project's issue tracker to coordinate attacks on third parties.
  Aegis is a defensive tool; the tracker is not a place to swap targets.

## Scope

This applies to the repository — issues, pull requests, discussions — and to any
communication where you are representing the project.

## Enforcement

Report problems to **darkzeit00@gmail.com**. Reports are handled privately.

Responses escalate as needed: a private word, a public correction, temporary
suspension from interaction, or a permanent ban. The maintainer makes the final
call, and will try to explain it.
