# Результаты сравнения Aegis vs Nginx — 2026-05-18

Стенд: один хост, оба прокси проксируют один и тот же бэкенд (nginx на :8000).

## 1. Чистая производительность (защиты Aegis приглушены для baseline)

| Тест                              | Aegis :80        | Nginx :8080      | Победитель |
|-----------------------------------|------------------|------------------|------------|
| Throughput `wrk -t4 -c100 -d10s`  | **108 286 RPS**  | **238 752 RPS**  | nginx ×2.2 |
| Средняя latency                   | 0.92 ms          | 564 µs           | nginx      |
| p99 latency                       | 1.88 ms          | 2.88 ms          | **aegis**  |
| Sustained flood `-t8 -c500 -d10s` | 103 802 RPS      | 253 408 RPS      | nginx ×2.4 |

## 2. WAF / инъекции (Aegis с дефолтным набором фильтров)

| Атака                                 | Aegis   | Nginx |
|---------------------------------------|---------|-------|
| SQLi `UNION SELECT`                   | **403** | 200   |
| SQLi `or 1=1`                         | **403** | 200   |
| XSS `javascript:alert(1)`             | **403** | 200   |
| SSRF `http://169.254.169.254/`        | **403** | 200   |
| Path traversal `../../etc/passwd`     | **403** | 200   |
| Cmd injection `;cat /etc/passwd`      | **403** | 200   |
| Time-based SQLi `WAITFOR DELAY`       | **403** | 200   |
| MySQL versioned comment `/*!UNION*/`  | **403** | 200   |
| 20× SQLi подряд с одного IP           | **20/20** | 0/20 |
